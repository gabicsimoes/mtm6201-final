## About the project:

## My process:
To start developing the final project, I created the repository on GitHub and then opened VS Code to structure all the folders and files I needed. I created an assets folder to organize images and icons into subfolders. After that, I created the page files: index.html, menu.html, and catering-events.html, plus the css folder with the main.css file, where I kept all the styling for the site.

With the structure ready, I started writing the base HTML for each page using the ! shortcut and naming everything according to the content. This time, I decided to work differently from previous assignments: instead of building all the HTML first and only then styling, I chose to work section by section. I created a part in HTML, styled it immediately in CSS, and only then moved to the next one. This helped me avoid rework and kept the layout more stable, since I could adjust the structure as I went.

I started with the Home page to establish patterns that would repeat across the other pages, such as the header, navigation menu, and footer. Then I continued with the remaining pages in this order: Home > Menu > Catering & Events.

I left the accessibility requirements for last, not because they are less important, but because I preferred to complete the bigger and more complex parts first. My logic was: finish as much as possible, and if something had to be left behind, let it be something smaller, not several scattered points.

About following the Figma design exactly: unfortunately, it wasn’t possible. I know my abilities and limitations, and web design is not my strongest area. It requires a lot of mental effort, research, and trial and error. So, to align expectations and achieve a decent result, I made some layout adjustments to make implementation easier, especially with grids, which are a weak point for me. All adjustments were made with the intention of doing the best I could within my current skill level.

Overall, I worked in small steps, adjusting HTML and CSS at the same time to avoid breaking the layout or having to redo large parts. About mobile-first: I still struggle to adjust my screen to the exact mobile size while using Go Live, so there are always a few buggy details on mobile, but fewer on tablet and desktop.

## Challenges:
To be very honest, my biggest challenge is programming as a whole, lol. It’s a completely new area for me, something I had never studied or even had interest in before, so it requires much more effort than other courses. It’s not something I naturally have aptitude for and just improve over time. It really pushes me out of my comfort zone.

Some specific challenges:

- **Grid organization:** both structurally in HTML (divs, wrappers, sections) and mathematically in CSS.

- **Remembering tags and subtags:** I constantly need to go back to class content to remember how to do certain things.

- **Responsiveness:** sometimes it feels like the code has a life of its own and refuses to cooperate, and in the end the problem was me, and relying only on myself to fix it is intense, lol.

- **Hamburger header:** I had to research and ask AI for help because I had no idea how to make the dropdown work and I didn't want to use Java Script because would be no sense once I have no idea of it.

- **Accessibility:** even though I think it’s important, I don’t value it as much as I should in code, I admit. Skip links make sense to me, maybe because they’re visible, but schema still doesn’t.

- **Headings:** in my Figma, several sections didn’t have titles, and the validator kept warning me. I don’t know if it was a planning mistake or if this happens in real life.

- **Time:** this was a huge challenge. The deadline was three weeks, but the first week was taken by UX prototypes. So in practice, I had two weeks, and one of them I had to prioritize other assignments to free up time for this one. In the end, it was eight days working for hours every day, and it still feels like it’s never enough.

Overall, there were many small challenges that appeared along the way, and I definitely mentioned several of them directly in the code comments.

## How I overcame these challenges:

I already explained most of this throughout the text, but in summary:

- I worked in small parts.

- I adjusted HTML and CSS at the same time.

- I reviewed class content whenever I forgot something.

- I researched when necessary.

- I adapted the design to something I could realistically execute.

- I accepted that I can’t do everything and made conscious choices.

## Image and asset attribution
All images were taken from [Unsplash](https://unsplash.com/), a resource recommended in the UX course.
Some food images had their backgrounds removed in Canva to keep a consistent aesthetic.

Icons (leaf, pepper, wheat, peanut) were downloaded from [The Noun Project](https://thenounproject.com/) and then styled by me in Canva and Figma.

SVG icons (hamburger, X, search, arrows) were created by me directly in Figma.

Fonts: Autour One and Inter, both from Google Fonts.

Frameworks: I didn’t use Bootstrap, only pure CSS, because I felt more confident working with something I’ve been learning for two semesters.
